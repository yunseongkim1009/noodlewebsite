# Noodle v7

index.html을 정적 호스팅에 올리거나 최신 브라우저에서 여세요. 모델·이미지·Three.js가 HTML 안에 들어 있어 런타임 빌드나 설치가 필요 없습니다.

첫 접속/새로고침 때 자동으로 약 7.5초 인트로를 재생합니다. SKIP INTRO 또는 Escape로 즉시 최종 앉기 상태로 이동합니다. 기존 말풍선과 기분 선택 기능은 유지합니다. 큰 히어로 일러스트의 반복 흔들림은 꺼져 있습니다.

로컬 미리보기:

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

http://127.0.0.1:8767/ 를 열면 됩니다. 강제 재생 옵션은 필요 없습니다.

source/에는 유지보수용 장면, 스타일, 기본 스킨 모델 데이터와 제작 스크립트가 있습니다. 런타임은 이미 index.html에 모두 포함되어 있습니다. sculpt.py는 requirements.txt의 Python 패키지를 설치한 개발 환경에서 모델 데이터를 다시 만들 때만 사용합니다. 모델 재생에는 Python이 필요 없습니다.

성능·프레임 출력·지원 범위는 Verification_Report_v7.md를 참고하세요. Three.js의 MIT 라이선스를 유지해 주세요.
